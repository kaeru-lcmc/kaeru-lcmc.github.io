プライバシーポリシー

制定日：2026年10月17日

work_center（以下「このアプリ」）は、利用者が自分のPCで使う個人用のアプリです。このページでは、このアプリがGoogleアカウント（YouTube）の情報をどのように扱うかを説明します。

1. YouTube API サービスの利用

このアプリは YouTube API サービス（YouTube Data API）を使います。YouTube の機能を使うことで、利用者は YouTube の利用規約 に同意したものとみなされます。Google による情報の扱いは Google プライバシーポリシー をご覧ください。

2. 受け取る情報

利用者がGoogleの画面で許可した場合に限り、次の情報を受け取ります。

  • チャンネルの識別子と名前、チャンネルの公開されている数（登録者数・総再生回数・動画の本数）
  • このアプリでアップロードした動画の識別子・公開の状態・予約した公開日時、公開されている数（再生回数・高評価・コメントの数）
  • アップロードの途中で通信が切れたとき、送れたかどうかを確かめるために読む、チャンネルの最近のアップロードの一覧（タイトルと日時。照合に使うだけで保存しません）
  • Googleが発行する許可の鍵（リフレッシュトークン。短い期限のアクセストークンは、使うあいだだけメモリに置きます）

求める許可は「YouTube への動画のアップロード（youtube.upload）」と「YouTube アカウントの情報の読み取り（youtube.readonly）」の2つだけです。メール、連絡先、そのほかのGoogleのサービスの情報は受け取りません。

3. 使い道

  • 利用者が作った動画を、利用者自身のチャンネルへアップロードし、公開の予約・サムネイルの設定・アップロード結果の確認をするため
  • 動画とチャンネルの数を、利用者自身が見るために画面へ表示し、日付ごとに記録するため

これ以外の目的には使いません。広告、販売、信用の判断、AIの学習には使いません。

4. 保存の場所と期間

受け取った情報は、利用者自身のPCの中のデータベースに保存します。許可の鍵は、PCのWindowsの保護された保存場所（資格情報マネージャー）に保存し、データベースやバックアップには含めません。開発者を含む第三者のサーバーへ送ることはありません。

保存した情報は、利用者がアプリやPCから削除するまで残ります。

5. 第三者への提供

受け取った情報を第三者に提供・販売・共有することはありません。通信するのは、YouTube API サービスを提供する Google だけです。

6. 許可の取り消しと削除

  • アプリの設定「販売・投稿先」の「接続を解除」で、PCに保存した許可の鍵を削除できます。
  • Googleアカウントのセキュリティ設定（サードパーティ製のアプリとサービス）から、いつでもこのアプリへの許可を取り消せます。
  • PCに保存した記録は、アプリのデータフォルダを削除すると消えます。

7. Google API サービスのユーザーデータに関するポリシー

このアプリが Google API から受け取った情報の使用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

8. 変更とお問い合わせ

このポリシーを変更するときは、このページを更新し、制定日の下に更新日を記します。お問い合わせは GitHub（kaeru-lcmc） へお願いします。

Privacy Policy (English summary)

work_center uses YouTube API Services. By using its YouTube features you agree to the YouTube Terms of Service; see also the Google Privacy Policy. With the user's consent the app requests only the youtube.upload and youtube.readonly scopes. It receives the channel's ID, title and public statistics, the IDs, privacy status, scheduled publish times and public statistics of videos it uploaded, the titles and dates of the channel's recent uploads (read only to confirm an interrupted upload, not stored), and an OAuth refresh token (short-lived access tokens are kept only in memory). This data is used only to upload the user's own videos to the user's own channel and to show their statistics to the user. All data stays on the user's computer (tokens in Windows Credential Manager); nothing is sent to the developer or any third party, sold, or used for advertising. Users can disconnect in the app or revoke access at Google security settings. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
